# Advisor App Automation

Maven/TestNG/Appium automation project for the Advisor Android application.

## Repository contents

- `src/test/java/` - page objects, tests, listeners, and utilities
- `pom.xml` - Maven dependencies and Surefire configuration
- `testng.xml` and module `*.xml` files - executable TestNG suites
- `reports/extent/` - selected final HTML report snapshot
